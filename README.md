# Annotated Papers Repository

A curated collection of research papers with personal annotations, notes, and insights.

> **New here?** Check out the [Quick Start Guide](QUICK_START.md) to add your first paper in 5 minutes!

## 📚 Purpose

This repository serves as a personal knowledge base for research papers I've read and annotated. Each paper includes:
- Original paper reference (link or PDF)
- Personal annotations and highlights
- Key takeaways and insights
- Implementation notes (where applicable)
- Related papers and references

## 📂 Repository Structure

```
annotated_papers/
├── papers/                     # Main papers directory
│   ├── machine_learning/       # ML papers
│   ├── deep_learning/          # Deep learning papers
│   ├── natural_language_processing/  # NLP papers
│   ├── computer_vision/        # Computer vision papers
│   ├── reinforcement_learning/ # RL papers
│   └── misc/                   # Other topics
├── templates/                  # Templates for annotations
└── PAPERS_INDEX.md            # Catalog of all papers
```

## 🚀 How to Use

### Adding a New Paper

1. Choose the appropriate category folder in `papers/`
2. Create a new folder with the paper name: `Author_Year_ShortTitle/`
3. Use the template from `templates/PAPER_TEMPLATE.md`
4. Add your annotations, notes, and insights
5. Update `PAPERS_INDEX.md` with the new entry

### Annotation Format

Each paper should follow this structure:
```
papers/<category>/<Author_Year_ShortTitle>/
├── README.md              # Main annotation file
├── paper.pdf              # Original paper (optional)
├── notes.md               # Additional notes
└── images/                # Figures, diagrams, etc.
```

## 📋 Paper Categories

- **Machine Learning**: Traditional ML algorithms, statistical learning
- **Deep Learning**: Neural networks, architectures, training techniques
- **Natural Language Processing**: Language models, text processing, NLP tasks
- **Computer Vision**: Image processing, object detection, vision models
- **Reinforcement Learning**: RL algorithms, policy optimization
- **Misc**: Papers that don't fit other categories
